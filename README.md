# 政務活動費をくらべる（仙台市・大崎市・宮城県）

仙台市議会・大崎市議会・宮城県議会の**令和7年度（2025年4月〜2026年3月）の政務活動費**を、会派ごと・費目ごとに比べられる市民向けのデータベースです。

- 仙台市議会：全11会派（会派×10費目）。市民の会の領収書60ページは試行的に文字化
- 大崎市議会：全7会派。出納簿の支出72件を全文検索可能
- 宮城県議会：7会派＋無会派議員1名（会派×10費目）

## 使い方
`index.html` を開く（GitHub Pages で公開）。各ページの「原本PDF」リンクで必ず原本を確認してください。データは `data-*.json` にあり、AIや表計算でそのまま使えます。

## 注意
- 非公式の試作版です。AIが各議会の公開資料（画像PDF）を読み取って作成しており、誤りがあり得ます。
- 費目合計は各議会の公表値と照合済みですが、領収書・出納簿の摘要の文字化は未校正の部分があります。
- 議員数・会派規模が異なるため、金額の大小だけで優劣は判断できません。
