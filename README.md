# 政務活動費をくらべる

[公開サイト](https://smile88405-dev.github.io/seimu-katsudohi-hikaku/)

仙台市議会・大崎市議会・宮城県議会の公表資料をもとに、会派別の収支、費目、年度ごとの変化を比較する非公式サイトです。PDF本文を検索し、原本の該当ページへたどれます。

## 収録範囲

2026年11月12日版。対象の公開PDFは2,296本、159,842ページ、収支集計は255会派・期間行です。

| 議会 | 収支比較の年度 | 公式掲載ページ |
|---|---|---|
| 仙台市議会 | 令和3～7年度 | [年度別執行状況](https://gikai.city.sendai.jp/disclosure/activity/yearly/index.html) |
| 宮城県議会 | 令和3～7年度 | [政務活動費](https://www.pref.miyagi.jp/site/kengikai/seimukatudouhi.html) |
| 大崎市議会 | 平成19～令和7年度 | [支出状況](https://www.city.osaki.miyagi.jp/shisei/shiseijoho/sigikai/5_1/2/index.html)・[過去の資料](https://www.city.osaki.miyagi.jp/shisei/shiseijoho/sigikai/5_1/2/21490.html) |

大崎市の平成23年度は交付申請なし。令和8年度は、公開済みの活動報告を検索対象に収録し、未公表の収支を0円として扱っていません。

## 使い方

1. 議会と対象年度を選び、会派別・費目別の収支を確認します。
2. 「年度を比べる」で、直近3年度と公開全年度を切り替えます。
3. 「PDF本文を探す」で年度の本文を読み込み、会派・資料の種類・検索語で絞り込みます。空白区切りはAND検索です。
4. 数値や引用する文章は、原本リンクから確認できます。比較データと検索結果をCSVに保存できます。

改選前後の期間、原表の費目名、修正履歴を保持しています。会派名が同じことだけで、所属議員の継続を推定しません。標準年額からの人数換算は目安で、実際の所属人数ではありません。

## 読み取りと検証

全ページのテキスト抽出または日本語OCRを実行し、原本SHA-256、実ページ数、ページ連番、会派別収支集計を照合しました。横向き・低文字数などの候補37,145ページも追加OCRの対象とし、元の読み取り結果を保全しています。比較・検索等の機能テストは61項目合格しています。

本文は機械文字起こしで、全文を人が校正したものではありません。手書き、罫線表、印影、黒塗りなどでは誤読・読み落としが残り得ます。領収書から支払先・金額・按分率を支出ごとに確定した台帳でもありません。個別の支出の適否や説明の十分さを、この集計だけで判断しないでください。

## 公開ファイル

- `app-data.js`：現行の収支集計、原本台帳、年度・制度情報
- `search/`：年度別のPDF本文検索データ
- `比較データ.csv`：全年度の収支比較データ
- `audit.json`：集計・読み取りの検証状況
- `release.json`：公開版のファイルSHA-256と収録件数

`sendai.html`、`osaki.html`、`miyagi.html`は、以前のURLを利用するための互換ページです。旧形式の`data-sendai.json`、`data-osaki.json`、`data-miyagi.json`は令和7年度版の旧データとして残しており、現行アプリでは参照しません。最新の比較値は`app-data.js`と`比較データ.csv`を使用してください。

静的HTML/JavaScriptとしてGitHub Pagesで公開しています。原本PDFのリンク先や公表値は、公開元の訂正・更新・公開終了によって変わる場合があります。
